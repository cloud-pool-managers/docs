# docs

Documentation de **Cloud Pool Manager** (MkDocs Material).

- En ligne : **https://cloud-pool-managers.github.io/docs/**
- Local : `pip install -r requirements.txt && mkdocs serve`

Le push sur `main` déclenche le workflow `docs` qui publie la version `latest` sur `gh-pages`
(servie par GitHub Pages). Sources des pages dans `docs/`.
